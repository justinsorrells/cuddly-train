# Decision log

Post-bootstrap judgment calls that are not contract changes but shape the
implementation (library structure, dependency versions, test strategy
choices). Contract changes do NOT go here — they amend the contract itself
with owner approval and a manifest regeneration.

One file per decision: `NNN-short-kebab-title.md` with:

```text
# NNN: Title
Date:
Status: accepted | superseded by NNN
Context:     what forced a choice
Decision:    what was chosen
Consequences: what this binds or rules out
Contract refs: §sections this interacts with
```

The five pre-bootstrap judgment calls are already recorded in contract §31
and are ratified with the contract, not duplicated here.
